# 顶层设计分析

## 问题：【循环单位】怎样形成清楚但不拖沓的双循环？

状态：agent_proposal

### 广度分析

> 填写要点：至少覆盖"极短 / 极长 / 被动推进 / 主动推进"四个方向的代价。

- 极短局外段能快速进入【局内段】，但【 】会失去存在感。
- 长局外段能提供【深度】，却会把【局内段】变成偶尔发生的支线。
- 以【现实时间/外部条件】推进会削弱玩家主动【推进】的动力。
- 以【玩家行动】推进循环单位，可以把【变化】直接绑定到玩家行为。

### 深度分析

> 填写要点：说明"这个循环必须是玩家能复述的完整因果链"，并解释每一段的时长与收益分配理由。

一段应是玩家能够复述的完整因果链：【查看状态】→【做少量决策】→【投入】→【验证】→【回流】→【进入下一循环】。

### 综合判断

以"【循环单位】"为循环单位；【局外段】保持【质感】但只承载关键决策，【局内段】承载核心体验，【结束方式】后统一结算并推进下一循环。

## 问题：风险、收益和长期成长怎样互相支撑？

状态：agent_proposal

### 广度分析

> 填写要点：覆盖"无损失败 / 全部掉落 / 主动选难度 / 分层奖励"四种收益结构的代价。

- 无损失败最轻松，但【投入与退出】都缺乏意义。
- 全部掉落能制造紧张感，却会把体验推向【硬核方向】。
- 主动选择难度倍率能快速制造风险收益，但会削弱【什么】。
- 【基础收益】【阶段奖励】【关键解锁】分层，可以同时提供短期回本与长期目标。

### 深度分析

> 填写要点：说清"惩罚上限"设计——失败应主要表现为少拿收益和延迟成长，而不是毁掉既有积累。

失败应主要表现为【少拿收益和延迟成长】，而不是【毁掉积累】。难度来自【内容深度/敌人组合/关卡结构】，而不是玩家在菜单里购买风险倍率。

### 综合判断

【资源 A】连接【两个循环】，【资源 B】服务【长期建设】，【Boss/关键节点】承担关键解锁；退出保留已得收益，失败只造成部分损失。长期成长以【第一主轴】为第一优先级、【第二主轴】为第二优先级，【角色数值】不得反客为主。
