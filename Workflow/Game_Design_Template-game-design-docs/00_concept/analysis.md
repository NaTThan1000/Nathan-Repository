## 问题：怎样防止内容扩张稀释核心幻想？

状态：agent_proposal

### 广度分析

- 增加【生活/社交/剧情】内容可以扩充时长，但不能强化【核心承诺】。
- 增加【数值/生产线/效率】可以制造深度，但容易把游戏变成【跑偏方向】。
- 增加【操作门槛/复杂系统】可以丰富内容，却会削弱【核心价值】。
- 增加【核心机制的直接扩展】才能直接放大核心承诺。

### 深度分析

> 填写要点：给出一个可复用的判断标准——新功能必须满足什么条件才允许进入核心范围。

判断新功能时，应追问它是否让玩家更清楚地感到"【因果句 1】""【因果句 2】"。如果答案是否定的，即使功能本身有趣，也不应进入核心范围。

### 综合判断

优先扩展【第一优先级】，其次扩展【第二优先级】，【第三项】只做辅助。其他内容只有在直接强化【核心因果】时才值得加入。
