# 甜界逃生 · 斜俯视键盘动作版 v3

直接双击「甜界逃生.html」，用 Chrome 或 Edge 打开。美术、逻辑、样式与合成音效均内置，无需联网、安装依赖或启动服务器。

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动与朝向 | WASD / 方向键，支持八方向；松开后保持最后朝向 |
| 攻击方向 | 由移动方向决定，单次攻击中锁定，鼠标不参与战斗 |
| 普通攻击 | J，可连续衔接三段 |
| 重攻击 | K，有前摇与收招；空中 K 是落斩 |
| 跳跃 | L，消耗 10 体力，可接空中普攻或落斩 |
| 闪避 | 空格；消耗体力，可取消攻击 |
| 闪避派生 | 闪避后 0.65 秒内接轻 / 重攻击 |
| 精准闪避反击 | 闪避穿过实际攻击后，1.25 秒内接轻 / 重攻击 |
| 更换餐具搭配 | X 循环搭配；R 工坊内用方向键选择、Enter 装备、R 返回 |
| 选择人类合体 | C |
| 发动合体 | Q，共鸣满后可用 |
| 三选一 | 1 / 2 / 3 |
| 暂停 / 手册 / 静音 | Esc 或 P / H / M |

按住攻击键不会自动连打；收招末段允许缓冲下一击。轻攻击、重攻击、闪避分别消耗 5 / 24 / 22 体力，停止消耗后会恢复。触屏也提供移动摇杆与轻、重、闪避、合体按钮；主要面向桌面纯键盘操作。开始界面 Enter 进入关卡，T 进入试招庭院；暂停后 Enter 继续，结算后 Enter 重开。

## 战斗规则

- 玩家靠手动近战出招；八种普通怪物中七种使用近战，糖果施术者只投掷有落点预警的单次区域攻击。没有环形弹幕和持续投射物。
- 普通敌人的薄荷色前摇可以打断，受击会进入硬直并产生位移。角色靠近怪物本身不造成接触伤害。
- 橙色 ◆ 表示霸体前摇 / 进攻，不会被普通命中打断，也不能用盾反招架，需要闪避或走位。Boss 重击削空架势后会失衡。
- 命中反馈包括角色待机 / 奔跑 / 普攻 / 重击动作帧，带白色刃口和多层残影的渐变弧光，穿刺流光、星芒爆闪、碎屑、受击变形、浮空击飞、击退、震屏与轻重不同的停顿及合成音效。数字伤害跳字已取消。
- 合体入场短暂无敌，之后仍需读招与闪避；12 秒内手动使用全新轻重招式，没有自动扫屏攻击。

## 餐具变体

拾取餐具一次即解锁，没有武器等级。四套单持与六套双餐具各自是一套互斥装备的招式；不是将多把武器的攻击同时叠加。X 快速轮换，R 查看并直接选择。

| 搭配 | 打法 |
| --- | --- |
| 叉＋刀：处刑双刃 | 轻击留下切痕；两段轻击后接重击引爆切痕，偏连段处刑 |
| 叉＋勺：翻糖长戟 | 长距离宽幅横扫；重击先勾拢，再延迟砸落，偏聚怪控场 |
| 叉＋吸管：虹吸长枪 | 长线突刺标记；重击抽回敌人并汲取少量生命，偏距离管理 |
| 刀＋勺：断层重铲 | 轻击积累碎甲；重击震地，碎甲敌人获得更长硬直，偏打断压制 |
| 刀＋吸管：糖丝链刃 | 鞭斩、长刺和周身回旋；重击勾拉怪群，偏移动控制 |
| 勺＋吸管：气压拳套 | 短打接打飞；重击先吸附再爆发击退，偏近身爆发 |

各餐具还有不同的闪避派生判定：长枪直线穿刺、链刃环身鞭击、长戟回钩、拳套升龙等。

## 人类与合体

第一关就能找到三名人类的糖笼，手动打破后接近即可救援，方便同一局内尝试多种合体。主厨与工程师的低频近战支援需要玩家正在出招，医师提供低频恢复。

| 搭档 | 合体招式变化 |
| --- | --- |
| 主厨＋工程师：熔炉机甲 | 重锤横扫；重攻击慢蓄力、大范围砸地并留下灼烧落点 |
| 医师＋工程师：缝合游侠 | 磁索勾拉并标记；重击触发已标记敌人的连锁震荡，再牵引怪群 |
| 主厨＋医师：白瓷圣卫 | 盾面扫击；重击前摇可招架普通近战，成功后手动接反震并治疗 |

三人都在队伍时，仍由 C 选择两人搭档，避免固定优先级替玩家决定合体。只有一位同伴时也有对应的单人共鸣形态；无人时可使用银翼武装。

## 成长与关卡

升级不提高基础伤害、攻速、最大生命，也没有武器 Lv.1～Lv.5。三选一主要解锁新餐具或规则变化：重击余震、第三段地裂、迎击招架、闪避回钩、重击后重置闪避、精准闪避留下治疗区等。机制只领悟一次，全部解锁后转为当前生命、体力与共鸣补给。

普通怪物的生命与伤害不会随时间和关卡成倍增长；关卡通过敌人组合与进攻人数变化提高压力。三关分别为奶油荒原、焦糖熔炉、冰霜王庭；每关三波，72 秒领主出现。Boss 生命为 1050 / 1230 / 1410，通过横扫、霸体冲撞和震地作战。

Boss 会封印已救同伴，但羁绊仍可用于手动合体；击败后同伴归队，生命恢复，选择改变招式规则的圣物，再进入下一关。第三关获得归途之匙并逃生。

- 当前打包入口：build.cjs，执行 node build.cjs 更新「甜界逃生.html」。
- 当前运行逻辑：src/action-game.js；src/presentation-v3.js 负责斜俯视投影、动作帧和技能特效；src/index.html 是页面和界面。src/game.js 是未接入构建的上一版源码，保留供参考。
- 美术：assets/characters.png 是原角色与怪物图集；assets/hero-motion-v3.png 是新增 4 × 4 主角动作图集；assets/promenade-v3.png 是新增甜品城场景。均通过内置 imagegen 生成。提示词见 assets/art-generation.txt 与 assets/art-generation-v3.txt。
- 运行 node tests/v3-check.cjs 或 node tests/browser-check.cjs，使用独立隐藏 Chrome 验证，不需要第三方 Node 包。
- 最新验证结果见 tests/v3-report.json，当前版截图前缀为 v3-。
- 测试覆盖真实鼠标与键盘输入、面向判定、普通打断、霸体抗打断、实际攻击碰撞与精准闪避、六种组合、三种合体、招架、机制成长、Boss 破势、三关流程及死亡重开。
- 通关流程使用测试接口加速并强制击败 Boss；80 怪物压力场景使用较高生命，不代表实际玩法的难度或击杀效率。数值、敌人节奏和手感仍属于可迭代 Demo。
- 当前没有存档、局外成长或联网功能。主角已接入待机、奔跑、普攻、重击动作图集；怪物仍以原图集配合程序受击与浮空动作呈现。场景采用二维斜俯视投影、直立精灵、前后遮挡与背景视差。


## v3 视角、技能与试招庭院

地面纵深按 0.49 系数压缩，人物与怪物保持直立比例，并按脚下位置作前后遮挡。场景由有远近层次的甜品城画作、较慢的背景视差、脚底投影与动态地面物件构成。攻击在地面坐标判定，视觉特效另有离地高度。

技能栏始终显示 J、K、空格与 L 的用途；当前 K 技能带具体操作提示。施放重击会显示技能名和连段提示。R 工坊同时显示搭配、技能名与按键顺序。

| 餐具 | K 技能与演出 | 怎么用 |
| --- | --- | --- |
| 叉＋刀 | 蔷薇十字 · 千层裁决：双重交叉斩光与切痕爆闪 | J → J → K |
| 叉＋勺 | 翻宴星坠：黄金巨戟坠落、地面裂纹与冲击环 | K 勾拢后延迟砸落 |
| 叉＋吸管 | 薄荷鲸落：薄荷鲸影、贯刺流光与虹吸气泡 | J 标记 → K 拉回并治疗 |
| 刀＋勺 | 布丁断头台：巨大瓷勺砸落与碎地冲击 | J 碎甲 → K 长硬直 |
| 刀＋吸管 | 银河糖丝：星屑链刃绕身，拉拢怪群 | K 周身回旋 |
| 勺＋吸管 | 苏打升龙：气泡螺旋升腾、巨型气压拳 | K 吸附后击飞 |

合体同样有独立演出：主厨＋工程师的「熔炉盛宴 · 天降餐锤」呈现巨大焰锤；主厨＋医师的「白瓷圣域 · 守望之翼」呈现圣盾、双翼与反震；医师＋工程师的「星河缝合 · 万象归席」呈现星环、磁索与标记连锁。

开始界面按 **T** 进入试招庭院：四种餐具和三名人类直接开放，木桩怪物不主动攻击，生命保持恢复，合体结束后共鸣自动填满。可以用 X / R 比较六种搭配，用 C / Q 比较三种合体。剩余木桩不足三只时重新布置，便于反复试招。

当前回归还覆盖鼠标完全不干预战斗、按键移动朝向、斜向输入立即出招、单次攻击方向锁定、跳跃落斩、斜俯视投影和纯键盘工坊装备。原 tests/action-check.cjs 保留为 v2 测试参考，标准入口已切换到 v3。
