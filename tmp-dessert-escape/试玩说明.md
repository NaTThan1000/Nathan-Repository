# 甜界逃生 · 试玩说明

直接双击「甜界逃生.html」，用 Chrome 或 Edge 打开。美术、逻辑、样式与合成音效均内置，无需联网、安装依赖或启动服务器。

## 操作

| 操作 | 输入 |
| --- | --- |
| 移动与朝向 | WASD / 方向键，支持八方向；松开后保持最后朝向 |
| 攻击方向 | 由移动方向决定，单次攻击中锁定，鼠标不参与战斗 |
| 普通攻击 | J，可连续衔接三段 |
| 重攻击 | L，有前摇与收招；空中 L 是落斩 |
| 跳跃 | K，消耗 10 体力，可接空中普攻或落斩 |
| 闪避 | 空格；消耗体力，可取消攻击 |
| 闪避派生 | 闪避后 0.65 秒内接轻 / 重攻击 |
| 精准闪避反击 | 闪避穿过实际攻击后，1.25 秒内接轻 / 重攻击 |
| 更换餐具搭配 | X 循环搭配；R 工坊内用方向键选择、Enter 装备、R 返回 |
| 选择人类合体 | C |
| 发动合体 | Q，共鸣满后可用 |
| 二选一 | 1 / 2 |
| 挑战领主 | 第三波清空后按 Enter |
| 切换练习 | 庭院内按 B |
| 暂停 / 手册 / 静音 | Esc 或 P / H / M |

按住攻击键不会自动连打；收招末段允许缓冲下一击。轻击不消耗体力。重击和闪避分别消耗 24 和 22 体力，停止消耗后会恢复。触屏也提供移动摇杆与轻击、跳跃、重击、闪避和合体按钮；主要面向桌面纯键盘操作。开始界面 Enter 进入关卡，T 进入试招庭院；暂停后 Enter 继续，结算后 Enter 重开。

## 战斗规则

- 玩家靠手动近战出招；八种普通怪物中七种使用近战，糖果施术者只投掷有落点预警的单次区域攻击。没有环形弹幕和持续投射物。
- 普通敌人的薄荷色前摇可以打断，受击会进入硬直并产生位移。角色靠近怪物本身不造成接触伤害。
- 橙色 ◆ 表示霸体前摇 / 进攻，不会被普通命中打断，也不能用盾反招架，需要闪避或走位。Boss 重击削空架势后会失衡。
- 命中反馈包括角色待机 / 奔跑 / 普攻 / 重击动作帧，带白色刃口和多层残影的渐变弧光，穿刺流光、星芒爆闪、碎屑、受击变形、浮空击飞、击退、震屏与轻重不同的停顿及合成音效。数字伤害跳字已取消。
- 合体入场短暂无敌，之后仍需读招与闪避；12 秒内手动使用全新轻重招式，没有自动扫屏攻击。

## 餐具变体

清完第二波后，从当局提供的两件餐具中选一件，立刻装备它与银叉的组合。击败领主后还能选择未解锁的餐具。四套单持与六套双餐具各有独立招式，每次装备一套。X 快速轮换，R 查看并直接选择。

| 搭配 | 打法 |
| --- | --- |
| 叉＋刀：处刑双刃 | 轻击留下切痕；两段轻击后接重击引爆切痕，偏连段处刑 |
| 叉＋勺：翻糖长戟 | 长距离宽幅横扫；重击先勾拢，再延迟砸落，偏聚怪控场 |
| 叉＋吸管：虹吸长枪 | 长线突刺标记；重击抽回敌人并汲取少量生命，偏距离管理 |
| 刀＋勺：断层重铲 | 轻击积累碎甲；重击震地，碎甲敌人获得更长硬直，偏打断压制 |
| 刀＋吸管：糖丝链刃 | 鞭斩、长刺和周身回旋；重击勾拉怪群，偏移动控制 |
| 勺＋吸管：气压拳套 | 短打接打飞；重击先吸附再爆发击退，偏近身爆发 |

各餐具还有不同的闪避派生判定，包括长枪直线穿刺、链刃环身鞭击、长戟回钩与拳套升龙。

### 专属连招

前置招式命中并满足表中条件后，操作栏会提示下一键。接招窗口为 1.45 秒。空中派生需要先按 K 跳起。按 R 可查看当前餐具的连招提示。

| 餐具 | 操作 | 效果 |
| --- | --- | --- |
| 处刑双刃 | J → J → L 引爆切痕 → J | 穿身回切，越过敌人后转身横斩 |
| 翻糖长戟 | L 勾拢和砸落均命中 → J | 扫糖尾，宽幅横扫并推开聚拢的敌人 |
| 虹吸长枪 | J 挂印 → L 虹吸命中 → J | 退步长刺，长距离刺中敌人后向后撤 |
| 断层重铲 | 地面 J 碎甲 → K → 空中 L | 碎甲坠铲，强化落斩并重创带碎甲印记的敌人 |
| 糖丝链刃 | 空格闪避 → J 命中 → L | 回卷链舞，把两侧敌人拉向身边 |
| 气压拳套 | 地面 L 命中 → K → 空中 J | 追空拳，向前突进追打浮空敌人 |

## 人类与合体

第二波清空并选完武器后出现第一个糖笼，其余糖笼在领主备战时出现。打碎糖笼后走近同伴即可救援。救援恢复最多 15 点生命并增加 25 点共鸣。命中敌人时，主厨会追加一斩，医师会治疗受伤的玩家，工程师会拉拢敌人并削减领主架势。每种支援有独立冷却，触发时会显示同伴名称。

| 搭档 | 合体招式变化 |
| --- | --- |
| 主厨＋工程师：熔炉机甲 | 重锤横扫。重击蓄力砸地，落点持续灼烧，灼烧伤害不打断前摇 |
| 医师＋工程师：缝合游侠 | 轻击用磁索牵引并布下印记，重击可远程引爆并消耗印记 |
| 主厨＋医师：白瓷圣卫 | 轻击出手后可立即接 L 架盾。挡住普通近战后，再按 L 反震，命中才治疗 |

按 C 选择搭档，左下角会高亮对应同伴。参与合体的同伴在变身期间并入角色，其余同伴可以继续支援。只有一位同伴时也有对应的单人共鸣形态；无人时可使用银翼武装。

## 成长与关卡

第二波清空时选武器。此后只在击败前两位领主时选择奖励。可以换新武器，或选重击余震、重击后刷新闪避等效果。

三关分别为奶油荒原、焦糖熔炉、冰霜王庭。每关三波，消灭当前敌人后才会推进。部分波次会从两侧夹击，护卫与施术者的位置也会随局翻转。前两波之间有 2.5 秒间歇，第三波清空后可以先救人、拾取补给或换装，再按 Enter 挑战领主。

千层暴君以横扫、冲锋和震地交替施压。熔心布丁王冲锋后会留下焦糖烫痕，冰霜女王震地后会在预先锁定的位置留下延迟霜圈。重击削空领主架势后，有 2.2 秒追击窗口，期间命中伤害提高 40%。

同伴会在领主战继续支援。击败领主后，生命和共鸣补满。圣物卡只列出这次会新增的招式。已学完部分圣物招式时，也可能出现未解锁餐具或能挡下一次伤害的糖衣。第三关获得归途之匙并逃生。

## 文件与验证

- 当前打包入口：build.cjs，执行 node build.cjs 更新「甜界逃生.html」。
- 当前运行逻辑：src/action-game.js；src/presentation-v3.js 负责斜俯视投影、动作帧和技能特效；src/index.html 是页面和界面。src/game.js 是未接入构建的上一版源码，保留供参考。
- 角色与动作图集在 assets/。奶油荒原、焦糖熔炉和冰霜王庭分别使用独立场景。新场景、合体立绘和动作图集由内置 ImageGen 生成，提示词保存在 assets/。
- 运行 node tests/v3-check.cjs 或 node tests/browser-check.cjs，使用独立隐藏 Chrome 验证，不需要第三方 Node 包。
- 检查结果与截图默认写入 tests/，可通过 SUGAR_BREAK_TEST_OUTPUT 改写输出目录。
- 测试覆盖真实鼠标与键盘输入、面向判定、普通打断、霸体抗打断、实际攻击碰撞与精准闪避、六种组合及其命中后专属连招、三种合体、招架、机制成长、Boss 破势、三关流程及死亡重开。
- 通关流程使用测试接口加速并强制击败 Boss；80 怪物压力场景使用较高生命，不代表实际玩法的难度或击杀效率。数值、敌人节奏和手感仍属于可迭代 Demo。
- 当前没有存档、局外成长或联网功能。主角已接入待机、奔跑、普攻、重击动作图集；怪物仍以原图集配合程序受击与浮空动作呈现。场景采用二维斜俯视投影、直立精灵、前后遮挡与背景视差。


## 视角、技能与试招庭院

地面纵深按 0.49 系数压缩，人物与怪物保持直立比例，并按脚下位置作前后遮挡。场景由有远近层次的甜品城画作、较慢的背景视差、脚底投影与动态地面物件构成。攻击在地面坐标判定，视觉特效另有离地高度。

首波战斗只提示移动和轻击。获得武器后，底部出现四个基础按键。按 R 可以查看每种武器的招式。角色有独立的起跳、腾空、着地、翻滚和受击姿势。空手攻击帧与武器图集分开，换武器时由引擎在同一只手上换装。长戟重击分为勾拢、举起和砸地，勾拢和砸地各自结算伤害。空手图集是 assets/hero-empty-handed-attacks.webp，武器图集是 assets/weapon-sprites.webp。武器尺寸、对应素材和绘制入口在 src/weapon-presentation.js。

| 餐具 | L 技能与演出 | 怎么用 |
| --- | --- | --- |
| 叉＋刀 | 蔷薇十字 · 千层裁决：双重交叉斩光与切痕爆闪 | J → J → L |
| 叉＋勺 | 翻宴星坠：黄金巨戟坠落、地面裂纹与冲击环 | L 勾拢后延迟砸落 |
| 叉＋吸管 | 薄荷鲸落：薄荷鲸影、贯刺流光与虹吸气泡 | J 标记 → L 拉回并治疗 |
| 刀＋勺 | 布丁断头台：巨大瓷勺砸落与碎地冲击 | J 碎甲 → L 长硬直 |
| 刀＋吸管 | 银河糖丝：星屑链刃绕身，拉拢怪群 | L 周身回旋 |
| 勺＋吸管 | 苏打升龙：气泡螺旋升腾、巨型气压拳 | L 吸附后击飞 |

三套合体各有独立立绘。主厨＋工程师的「熔炉盛宴 · 天降餐锤」呈现巨大焰锤；主厨＋医师的「白瓷圣域 · 守望之翼」呈现圣盾、双翼与反震；医师＋工程师的「星河缝合 · 万象归席」呈现星环、磁索与标记连锁。

开始界面按 **T** 进入试招庭院：四种餐具和三名人类直接开放，木桩怪物不主动攻击，生命保持恢复，合体结束后共鸣自动填满。可以用 X / R 比较六种搭配，用 C / Q 比较三种合体。剩余木桩不足三只时重新布置。按 B 可切换到单个主动对手，练习打断薄荷色前摇，或穿过橙色冲锋接精准反击。击倒陪练后会再生成一只。

当前回归还覆盖鼠标完全不干预战斗、按键移动朝向、斜向输入立即出招、单次攻击方向锁定、跳跃落斩、斜俯视投影和纯键盘工坊装备。原 tests/action-check.cjs 保留为 v2 测试参考，标准入口已切换到 v3。
