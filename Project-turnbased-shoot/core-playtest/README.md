# 核心战斗试玩原型

## Scrap Star 美术试玩（2026-11-03）

当前 `index.html` 已接入审核通过的 Scrap Star 角色四向动作、近战与远程机器人、房间部件、四向门、设施、箱子、子弹、命中与消失特效、范围提示及 UI。默认进入“Scrap Star · 设施与箱子”；控制面板可切回原战斗场景。此原型仍是单房战斗测试，门表现开闭状态，不提供房间切换。

箱子四次攻击依次显示 1、2、2、3 帧，第 4 次攻击后播放 4～6 帧并移除阻挡。远程机器人本体不含子弹；子弹独立渲染。玩家飞行弹体统一使用金色子弹，命中和射程结束播放火花／碎片。

`index.html` 是可双击运行的独立产物，图片全部内嵌。修改 `scrap-star-runtime.js`、`scrap-star.css` 或审核素材后运行 `node core-playtest/build-scrap-star.cjs` 更新它；此脚本保留现有战斗代码，不使用下述旧 `build.cjs`。先通过 `node core-playtest/test-ordered.cjs` 检查战斗规则，再通过 `node core-playtest/test-scrap-star.cjs` 做真实图片解码和 Canvas 渲染检查。后者使用模拟 DOM，不代表浏览器布局、输入和完整试玩验收。

双击 index.html 打开，图片和配置已内联。WASD 移动、方向键射击、Space 结束回合、Esc 回溯。右上面板选择场景、重置、换种子、导出本机记录；自定义组合为裂口尸 I 和浮游眼 I，合计 1–8 只，浮游眼目前面板上限 4 只。

## 2026-11-02 当前规则与状态

- 根据局面预先固定一套随机结果，只模拟一条顺序行动；结束回合复用，不穷举所有随机分支。局面变化后重新判断。
- 先射击阶段、后移动阶段；逻辑依固定距离／ID 顺序逐只完整结算，阶段内动画一起播放。命中节点才表现受伤、无敌、近战效果和碰撞挤出。
- 感叹号选择射击阶段可命中的最近来源，其次移动阶段。显示该怪物完整潜在范围，无敌也显示，结束回合后保持此前范围；每怪物回合最多一次怪物伤害，来源失效时保留并回退真实命中。
- 裂口尸 I 最多移动两格，到相邻攻击位置即停；浮游眼射线覆盖玩家时射击，否则游走。保留碰撞伤害，玩家可以穿过怪物，怪物撞玩家尝试四邻挤出。
- 本原型是独立试玩分支快照，没有掉落、炸弹和房间切换；不代表全部怪物已人工验证。正式版已按最终决定移植，入口为 ../turnbased-shoot-demo-pack.html，用户稍后完整测试。

## 已知差异与维护注意

- 原型仍保留“剩余移动点必须足以离开怪物格”的旧输入限制；回合末重叠挤出的距离仍为几何距离。正式版已按最终决定允许末步进入并使用房内可通行最短步数寻找终点、落脚触发格子效果。继续修改原型前需先核对这些差异，不能直接以它覆盖正式版。
- test-ordered.cjs 是本轮原型检查（模拟 DOM）；test.cjs 含旧穷举覆盖、无碰撞等断言，不适用于最终规则，本轮执行会失败。正式版测试为 ../tests/danger-forecast.test.js。
- build.cjs 是早期从正式打包版逐次补丁生成的脚本，未收录后来全部直接修改，不能直接运行覆盖 index.html。保留供追溯；后续需要重建时先整理可复现构建过程。
- 本轮没有完整浏览器验收；多次推挤、不同路径长度和全部 Boss 的表现需在正式版试玩反馈。

测试：node core-playtest/test-ordered.cjs（在项目目录运行）。试玩记录保存在当前浏览器本机存储；导出只输出用户已有测试记录，不包含正式游戏存档。
