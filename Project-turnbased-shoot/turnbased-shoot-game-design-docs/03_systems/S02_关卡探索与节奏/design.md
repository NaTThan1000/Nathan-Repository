# S02 关卡探索与节奏

> 设计草案。已确认的顶层目标与边界已汇总，已确认首轮使用固定的房间与怪物组合。
> 上游：[系统架构](../../02_architecture/design.md)
> 相邻：[战斗与危险应对](../S01_战斗与危险应对/design.md)

## 设计目的

玩家推进一层时，能在紧张战斗和放松探索之间切换。怪物与地形的搭配影响站位、目标和行动顺序。战斗之后，玩家有时间寻找资源、比较收获并整顿构筑。楼层推进带来不同的应对局面，为不断成长的构筑提供检验机会。

## 责任与接口

| 内容 | 关卡负责的部分 | 与其他系统的关系 |
|---|---|---|
| 楼层与房间 | 布局、连接、房型、进出与推进状态 | 向战斗提供空间、障碍和遭遇条件 |
| 遭遇与清房 | 设置房间遭遇，按结算事实更新通行和推进 | 战斗提供击杀、遭遇结束或本局失败等事实 |
| 探索与奖励机会 | 决定房间中可探索、可领取或可消费的位置与机会 | 构筑与资源处理奖励内容、生成和领取 |

## 单层循环

进入楼层，探索房间。遭遇怪物时进入战斗，结算后恢复房间通行，并按配置提供相应的奖励机会。玩家在非战斗时段可以搜寻、取舍和整顿，之后继续探索或挑战 Boss。通往下一层的条件由关卡根据战斗结果更新，整局以通关或失败结束。

## Boss 房进入条件

玩家到达与 Boss 房相邻且相连的房间，清空该房的怪物，待通往 Boss 房的门开放后即可进入。Boss 房沿用现行通行规则，无额外入场条件。

## Demo范围

- 首选6层、30～40分钟。成本过高时先同步，再考虑3层、15～20分钟。
- 允许每两层高度复用怪物，通过布局、搭配和阶段变化产生不同应对。
- 普通区域以大多搜全为目标。首轮以基础探索、战斗和构筑的完整单局为重点，完整探索差异留待后续。
- 房间地形和怪物遭遇作为一组配置。首轮人工设定固定房间和怪物组合，验证通过后再开发以组合为单位的随机生成。
- 固定对象是房间与怪物组合。第一轮的道具掉落、敌人行动随机和出生点的具体固定范围仍待确认。
- 下一项是每层是否常备商店和宝物房，见[关卡分析](analysis.md)。随后安排各层战斗和整顿的节奏、房间任务与内容预算。

## 验证标准

1. 布局与阵容的组合是否使玩家调整走位、目标优先级或行动顺序？
2. 战斗和探索整顿是否节奏分明，非战斗状态下是否有时间慢慢取舍？
3. 复用怪物时，玩家是否仍能感觉到前中后段和不同楼层的变化？
4. 完整单局耗时是否接近目标，明显重复或停顿发生在哪些段落？
