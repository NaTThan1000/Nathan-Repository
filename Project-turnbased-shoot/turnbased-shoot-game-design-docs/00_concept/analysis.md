# 概念设计分析

## 问题1：这个游戏最需要兑现的核心承诺是什么？

状态：confirmed

日期：2026-11-08

### 已有依据

- 2026-11-05记忆明确：面向操作能力较低的玩家，结合十字射击与半回合制，让玩家感受危险与刺激，同时拥有充分思考时间并经历多样战斗。
- 当前正式规则：一步或一枪推进世界；安全闪避确定攻击后获得2次冻结场景的额外行动。
- 2026-11-06记忆：子弹时间贵重性、旧道具适配与整层体验仍待验证。

### 广度分析

已有诉求涉及低操作门槛、判断危险与闪避反攻、随机道具带来的变化。前两项已有明确目标和机制支持；随机构筑与单步玩法的结合尚未完成适配。需要确认这些体验的主次，不能仅凭当前完成度判断重要性。

### 深度分析

单步推进提供观察与思考时间，锁定攻击预告支持有依据的闪避，冻结奖励提供集中反攻的机会。这条因果链能够承载“看懂危险、做出应对、获得反攻主动权”。是否足够刺激、奖励是否值得期待，仍需试玩检验。

### 初始判断与待确认点（保留讨论过程）

让操作能力不强的玩家也能体验射击战斗的危险与反攻快感：有时间看懂局面，通过走位化解攻击，并抓住闪避后的子弹时间主动反击。

待确认：这是否是最重要的核心承诺，随机构筑的爽感是否需要占据同等地位？

### 用户确认与最终结论

用户确认基本方向符合，并明确：“随机构筑爽感和射击战斗的危险与反攻快感各占一半，同等重要。”

核心承诺：让操作能力不强的玩家也能享受随机构筑带来的爽感，以及射击战斗中的危险与反攻快感。两者同等重要；单步推进提供思考时间，走位与子弹时间承载化解危险、主动反攻的体验。

“各占一半”记录为设计重要性同等，不据此推定游玩时间、内容数量或开发资源各分配一半。

## 问题2：怎样判断新增内容是在强化核心体验，还是让项目偏离目标？

状态：confirmed

日期：2026-11-08

### 广度分析

只围绕走位与闪避扩展，会遗漏已确认的构筑爽感；只围绕随机奖励与伤害提升扩展，也可能让危险与反攻失去发挥空间。分别强化其中一项的内容可以有价值，整体设计则需检查两项体验能否共同成立。

### 深度分析

构筑可以通过数值成长、攻击效果与组合获得爽感，不必每件道具都改变操作。战斗内容可以通过敌人、地形与阵容，让玩家需要观察和应对。两者相遇时，应既能感到构筑的力量，也有理解危险、化解攻击并反攻的机会。强势构筑可以带来碾压时刻；碾压出现的频率与持续范围尚待讨论。

### 综合判断（待确认）

新增内容应能说明它如何强化构筑爽感或危险与反攻快感，并在整体流程中检查另一项是否仍有发挥空间。暂以两项体验能相互增强为取舍标准，避免长期只剩机械射击，或构筑差异无法被玩家感知。

### 用户确认的取舍

用户接受：好构筑可以阶段性碾压，暂时跳过危险与反攻；整局仍应保留需要认真判断和应对的战斗。

## 问题3：核心目标玩家愿意承担怎样的思考负担？

状态：confirmed

日期：2026-11-08

### 已有依据

此前项目目标为低操作门槛、轻至中等策略、偏轻松爽玩；最新确认将构筑爽感与危险、反攻快感并列。

### 分析与待确认判断

核心玩家可能喜欢随机道具组合和地牢射击，但不擅长或不愿持续承担即时反应压力。他们愿意观察预告、判断走位并做短程选择，希望这些判断能较快转化为战斗反馈。单步推进已降低反应压力，是否也需要严格控制每步推演负担，仍需确认。

建议定位：允许关键局面停下来想，日常多数行动凭直观判断推进；把反复推算多步最优解的需求控制在较低水平。这是待确认的目标，不是当前体验验收结论。


### 用户确认

用户确认目标玩家与思考状态符合预期：日常多数行动凭直观判断推进，关键局面再停下来认真想，不要求经常推算多步最优解。

## 问题4：玩家为什么想继续这一局，并开始下一局？

状态：confirmed

日期：2026-11-08

### 已有依据

构筑爽感与危险、反攻快感同等重要；允许阶段性碾压；目标为低操作门槛、轻至中等策略。现有正式版已有多房间、楼层、随机道具和Boss，局外成长尚未实现。

### 分析与待确认判断

推测单局内的期待是：继续寻找能让当前组合变强或出现新效果的奖励，把获得的力量用于后续战斗，并尝试走得更远、击败Boss。下一局的期待是：遇到不同的道具组合和战斗局面，体验另一种成长与应对过程。

建议先以“这一局能组成什么、能走多远；下一局又会有什么不同”作为持续游玩的主要动机。局外永久成长在这个动机中承担多大作用尚未确认，不能从现有未实现推定为不需要。

### 用户补充与确认结论

- 继续这一局：期待后续会遇到怎样的怪物和Boss；获得强力效果、当前怪物变简单后，也期待用更强的怪物检验强力构筑。
- 开始下一局：除不同的组合和战斗局面外，期待局外成长让开局更强，让再次变强更近、更值得期待；也包含继续这一局的全部理由。
- 因此，持续动机同时包含构筑成长、未知敌人与Boss的发现、用强力构筑挑战强敌，以及局外成长带来的更强起点。局外成长已确认为期望体验，具体实现与重要性比例尚未确定。

## 问题5：成长变强与战斗挑战应怎样相处？

状态：confirmed

日期：2026-11-08

### 分析与待确认判断

用户希望强力构筑使当前怪物变简单，也希望遇到更强的对手检验构筑；局外成长应让新一局开局更强。由此推断，成长需要在实际战斗中体现为优势，过去难应对的敌人可以逐渐变得轻松；后续更强或不同机制、组合的对手，再提供新的应对目标。

待确认的原则：保留玩家超越既有挑战的成就感，同时让后续仍有值得挑战的对手。此处只确认体验方向，敌人强度如何配置、是否有动态调整等具体规则留待下层设计。

### 用户补充与确认结论

用户认可超越既有挑战、由后续更强或不同对手承接挑战的方向，并补充：学习怪物和Boss行为也应占一定比重。初次打不过同一敌人，可能源于不熟悉；多次挑战后，玩家应能提高规避风险和击败Boss的概率。

玩家对敌人的学习与角色成长共同支持战斗推进：规避风险的能力提高，角色也逐步变强，从而能战胜更强的敌人、生存更久，并进一步获得更强的构筑。这里的“构筑等级”暂按构筑强度理解，未据此定义新的等级系统或解锁方式。

### 待下层验证

已确认低操作门槛、日常直观判断、关键局面认真思考；敌人学习需与这些目标共同成立。学习与数值成长各自的贡献尚未量化。

## 问题6：玩家不熟悉敌人而失败时，希望留下怎样的感受？

状态：confirmed

日期：2026-11-08

### 分析与待确认判断

既然重复挑战需要积累对敌人行为的理解，初次遇敌可以因不熟悉而受伤或失败，但经历应让玩家逐渐认识危险及应对方式。结合低操作门槛与轻至中等策略目标，建议失败后主要留下“我知道哪里没应对好，下次换个做法，再配合成长能走得更远”的期待。

这是待确认的情绪目标。失败损失、提示形式、具体学习门槛均留待后续设计。

### 用户确认

用户确认失败后的目标感受：“有点可惜，这套构筑还想继续玩。不过我知道刚才哪里没应对好，下次换个做法，再加上成长，应该能走得更远。”失败同时包含对当前构筑的惋惜、学习所得和重试期待。

## 问题7：整局游玩的情绪基调是什么？

状态：confirmed

日期：2026-11-08

### 分析与待确认判断

已确认日常直观推进、关键局面认真思考，构筑可阶段性碾压，失败后保有学习与重试期待。由此建议整体游玩以好奇、期待变强和爽快为底色，战斗中的危险带来局部紧张，闪避反攻、构筑成型与战胜强敌带来释放和满足。

这是一项关于游玩情绪的提案，美术、世界观与叙事风格仍待确认。待确认：上述情绪关系是否符合预期，还是整局应持续保持更强的压迫感？

### 用户确认

用户确认：整局以好奇、期待变强和爽快为底色，危险战斗带来紧张，成功应对与构筑成型带来释放和满足。此确认针对游玩情绪。

## 问题9：一句话概念是否准确概括已确认的设计？

状态：confirmed

日期：2026-11-08

### 分析与待确认判断

概念需要同时体现低操作门槛、随机构筑、危险与反攻，以及学习和成长。太空废土／废弃飞船逃亡作为暂定背景单独标记，不锁定为最终题材。

建议一句话概念：《Turnbased Shoot》是一款低操作门槛、紧张而爽快的单步制Roguelite射击游戏：玩家在探索中组合随机道具，通过观察、走位与子弹时间反攻挑战怪物和Boss，并凭借对敌人行为的学习与局外成长逐次走得更远。

暂定叙事目标：从太空废土或废弃飞船中逃出去。该表述不定义通关后重玩、失败复活等叙事规则。

### 用户确认

用户确认目前描述准确，同时保留后续调整的可能。本句作为当前阶段的概念基线，后续调整记录新结论与原因。

## 问题10：哪些方向应列为当前非目标？

状态：confirmed

日期：2026-11-08

### 分析与待确认判断

低操作门槛、日常直观推进与两项核心体验同等重要已经确认。可据此整理两项非目标：不以持续高反应操作作为主要难度；不以日常频繁多步最优推演作为主要乐趣。这些是已有目标的边界表达。

另一个尚未决定的边界是局外成长的必要程度：它可以提供更强起点，但是否允许成为通关前反复积累的必要门槛？建议优先支持学习敌人、改善应对和局内构筑带来突破，让局外成长增加容错与期待，避免玩家面对明显强度缺口时只能重复积累。此建议尚未确认，不等于禁止局外成长有显著收益；成长幅度、通关条件和具体规则留待顶层设计。

### 用户确认与补充

用户同意局外成长帮助突破的定位。它还可以提供影响游戏机制的能力，形成实际体验明显不同的阶段性提升。用户以其他平台跳跃肉鸽中的二段跳为例；十次、二十次是举例语境，不是本项目解锁次数，二段跳也不是本项目已采纳能力。

因此，帮助突破并不等于仅增加数值或容错；改变玩法的能力解锁也可成为局外成长的期待。具体能力、获得条件及其与挑战的关系留给后续层级设计。
