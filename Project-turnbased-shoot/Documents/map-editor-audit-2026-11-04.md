# 地图编辑器审计与参数试验建议

> 后续状态：本文初次审计的13×7/MP4建议已被本轮用户授权的13×9测试原型、MP/AP3及更快节奏取代；正文初次建议作为历史保留。编辑器本身仍13×7。原型九房间和右侧面板见项目context最新说明。daily end在隔离源码重建两包并通过verify，仅提交地图/原型范围，不包含并行回溯、世界UI或美术扩展。

范围：独立编辑器 turnbased-shoot-map-viewer.html、Configs 地图与怪物配置、游戏地图加载及刷怪入口。本轮只修改编辑器和新增其回归检查，没有修改游戏参数、现有地图 JSON、项目记忆或游戏打包文件。

## 已修复

1. 备用文件导入循环读取六层，现有数据只有三层，第四层访问会失败且留下部分更新。改为先检查三层 rooms，再导入三层。
2. 启动读取 pool 缓存或已授权文件时清除模板草稿。取消启动清除；用户显式选择新文件仍沿用替换草稿行为。
3. 两条楼层导出路径丢弃实际 grid。现在导出行优先格子快照，游戏已有行优先转置和优先读取 grid 的能力。模板后来变化不会偷偷改变已经导出的楼层；想更新该楼层的布局需要重新生成并导出。现有 floor-data.json 未被改写。
4. 文件写入失败后仍提示保存成功；没有文件句柄时也声称持久化。现在区分缓存、文件写入成功与失败；没有写入文件时提示手动导出。
5. 编辑模板丢失 allowedMovement 等附加字段。现在保存完整模板对象。
6. 无放回抽选第二个图案仍使用原权重总和，产生偏差。改用剩余图案权重总和。
7. 格子行数、列数及非法字符没有显式校验。新增结构校验；显式导入模板池时在替换数据前检查模板。

## 新增编辑辅助

显示不可行走地形占比、尖刺数量、从门位不可达的可行走格数、单出口死端格数、最远门间最短路径，以及 MP3/MP4 的纯移动回合估算。尖刺按可行走格处理；诊断不模拟伤害、飞行、炸弹、怪物占位或真正战斗回合。

自动生成增加用途筛选，继续使用原有图案：战斗与探索侧区模式均要求没有孤岛、不可行走地形8～23格、尖刺至多4格、最远门距至多20步；战斗模式额外限制死端格至多2格。探索侧区模式仅放宽死端限制，不保证存在奖励支路。原图案模式保留原有筛选边界。以上阈值均为编辑试验起点，不是经过平衡验收的标准。生成仍为编辑时操作，导出后不会每次开局重新生成地图。

## 仍存在的边界

- 模板通过连通检查不代表通道足够宽，也不代表2×2 Boss能绕行。尚未加入瓶颈、双路径或多格单位通行诊断。
- 编辑器预览的是地形、房间连接及门锁，不包含精确敌人布置。游戏 spawnMonsterAtRandomPos 仍随机选择合法出生格；地图固定不代表整场遭遇完全固定。若需要严格复现，后续应单独设计固定刷怪配置与编辑界面。
- 浏览器缓存仍可能与磁盘文件不同；生成 JSON 不等于已覆盖项目配置，游戏包还需在确认配置后重建。
- 显式选择新的 pool 文件会替换本地草稿；本轮未新增合并冲突界面。
- 编辑器仍有独立于游戏的常量、内置模板和楼层生成实现，存在长期漂移风险。本轮未将其重写为共用模块。
- 尚未实现房间实例绘制、奖励与出生点放置、模板尺寸切换、视野遮挡或隐藏区域。

## 优先试玩参数（建议，未应用）

先比较13×7、MP4、AP3、射程6与当前MP3基线。移动加1可增加绕障、取得射击角度的余地；同时提高AP会改变单回合击杀能力，扩大房间则会改变接敌距离，应分步验证。

初始攻击3.5，裂口尸I生命10、浮游眼I生命6，在只考虑基础命中的条件下分别需3发、2发。AP3已有一次处理一个基础近战怪或处理远程怪并余一发的预算，暂不建议同时增加。

普通近战移动建议保留2/3/4格分级，邻格攻击范围保留1；先不随玩家MP同步增加。远程射程4/5/6先保留；若实测追赶拖沓，优先单独比较射击后游走1/2/2与当前2/3/4，不同时缩射程或削弱全部行为。冲刺和Boss落点威胁独立保留特色，不统一压成普通移动距离。

若MP4及短障碍布局仍经常缺少第二条路线，再比较13×9、MP4；新增面积主要承载纵向绕行带和侧区。不要因为面积增加就按比例加怪，否则无法辨别空间本身的影响。关注无有效攻击的移动回合、入口退出空间、追赶远程怪、绕障开火以及奖励支路是否值得走。
