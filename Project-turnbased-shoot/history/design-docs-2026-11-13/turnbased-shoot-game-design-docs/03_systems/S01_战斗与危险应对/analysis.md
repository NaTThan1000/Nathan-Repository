# 战斗与危险应对分析

## 首轮采用当前单步规则

状态：设计工作基线，体验待验证

当前正式规则已有一步一行动、预告、无伤规避和两次额外行动。用户的六项试玩标准要求验证读懂危险、规避反攻、出彩行动与地形和怪物配合。首轮沿用现行规则，先识别体验差距。该工作判断沿用既有设计，具体触发价值与整局节奏仍需实玩判断。

如果规避频繁触发却没有有价值的反攻目标，先检查阵容、目标位置和下一步战斗压力。如果玩家无法辨别哪格安全，先检查危险信息与结算。如果玩家读懂了也难以连贯操作，再检查动作完成与输入释放。记录不同原因，避免将三类问题合并为单一的触发门槛问题。

## 建议的三类对照场景

状态：试玩计划，待执行

| 对照 | 观察重点 | 用于区分 |
|---|---|---|
| 同一攻击分别原地承受、成功避开、避开一个威胁却受到另一个伤害 | 原位置是否会被击中、实际伤害、额外行动触发及恢复时点 | 规则结算错误与危险信息误读 |
| 同一阵容分别置于开阔布局与有遮挡布局 | 安全落点、击杀优先级、反攻选择及遭遇是否需要不同策略 | 地形与阵容的设计配合和单纯的数值压力 |
| 同一遭遇比较基础装备和可明确识别的构筑组合 | 实际射线、站位、击杀顺序及玩家对变强的解释 | 构筑是否改变应对与是否只在木桩上更强 |

固定对照用于定位问题。整局试玩额外记录什么时候感到紧张、何时成功扭转局势，以及何时开始重复。若体验问题只在后段出现，再回到关卡与构筑检查内容密度、阵容和奖励节奏。
