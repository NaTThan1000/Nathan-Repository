# 关卡探索与节奏分析

## 首轮关卡配置（已确认）

当前实现从楼层数据读取房间和地形，首次进入房间时按符合条件的小队和可用位置生成遭遇，现有流程仍有阵容与站位随机。

建议首轮完整单局先固定楼层地图，以及主要战斗房的敌人组合和起始位置。保留局内随机道具与构筑变化，敌人行动仍按现行规则结算。固定的遭遇让同一房间可重试，也便于比较不同构筑怎样应对同一布局。随后可通过试玩检查固定序列是否能支撑前中后段的节奏。

也可以沿用当前的固定地图加随机遭遇作为首轮流程。它更早暴露不同阵容下的体验波动，并可沿用当前刷怪流程。要解释某段体验偏难或偏长，则需要记录当局实际阵容和起点，或另用固定对照复测。

用户确认将房间地形与怪物遭遇绑定。首轮人工设定固定房间和怪物组合，验证通过后再开发房间与怪物组合的随机生成。此前固定出生点和保留随机道具的建议属于额外细节，当前决定未单独锁定这些条件。

## Boss 房进入条件（已确认）

建议玩家打通前往 Boss 房的路线后即可挑战，也可以回头探索可选房间、获取资源并整顿。这样可以保留普通区域大多搜全的预期，也让玩家决定何时准备好继续推进。

另一种结构是设定必打房间或其他入场条件。它能保证玩家在 Boss 前经历关键遭遇，有利于验证规定的节奏与成长，但玩家可自主决定的推进空间会减少。即使允许到达即挑战，也可以通过房间连接让主要路线包含所需的关键遭遇。

用户确认沿用现行规则。玩家清空 Boss 房前相连房间的怪物，门开放后即可进入。只读核对表明当前三层 Boss 房均未配置钥匙锁，正常房门的通行由本房存活怪物状态控制。

## 下一项待确认：每层是否常备商店和宝物房？

当前三层均配置商店和宝物房，部分房间受现有门锁条件限制。建议首轮每层都保留两类可选机会。宝物房提供随机收获，商店提供消耗金币的主动选择。它们和清房后的探索共同承担放松与整顿节奏。

另一种布局是让部分层缺少其中一类房间，用清房后的探索或其他现有奖励承担该段的成长。这样各层节奏差异更大，但道具获得与金币消费的时点会变化，需要留意构筑进度和资源积压。具体摆放、开锁和每层房间数留到试排确定。
