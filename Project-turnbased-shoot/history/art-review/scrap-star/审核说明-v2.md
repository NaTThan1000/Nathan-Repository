# Scrap Star 素材审核说明（第二版）

此说明对应同目录的第二版审核包。项目现用页面见 [审核预览.html](../../../Assets/scrap-star-review/审核预览.html)。本页每个用途只选用一套素材，隐藏旧版效果图与备用候选；四方向门以“房间墙和门”中的部件为准。

角色按方向展示，喷气移动、射击和受击分组查看；子弹单独展示，不再拼接到角色身上。预览根据图内每帧实际位置截取，以同一尺度及基准线显示；原图中角色自身的姿势变化仍会呈现。房间和 UI 为原始素材图的一部分，未接入实际游戏。

原图仍是生成的序列合图，未产出独立切片；本页不是试玩版。原项目中的所有旧文件仍保留，未删除。
