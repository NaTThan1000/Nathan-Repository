- [基础 UI 图标和面板](../../../Assets/scrap-star-review/ui-draft.png)：心形、AP／MP 槽、攻击力、射程、金币、炸弹、钥匙、帮助和回溯。
- [回合提示、状态条及槽位](../../../Assets/scrap-star-review/ui-turn-and-status.png)：蓝／红提示框、状态条和道具槽。
- UI 图标仍在合图中，未拆成单张；数值及本地化文字并非图片素材。
