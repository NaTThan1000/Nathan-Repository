# 保存与恢复覆盖表

`state-prediction-regression.test.cjs` 对 `playerStats` 和 `playerResources` 检查完整字段名清单。新增字段会让检查失败，维护者需要明确它是否参与回溯，并更新保存、各恢复路径和测试夹具。其他对象目前没有自动枚举完整性保证，新增特殊能力仍需人工确认。

预测隔离检查以裂口尸、浮游眼、跳跃 Boss、公爵为代表：冻结输入、同种子结果一致（含 Map／Set）、不改真实状态和快照、不调用真实 Math.random／音效、返回对象与真实对象分离。现有 danger-forecast 检查另覆盖14种配置、56种行动阶段及混合回合。这些是模拟 DOM／Canvas 自动检查，不等同于完整浏览器人工验收。

本轮未合并预抽掉落与即时掉落，也未重写预测规则的源码序列化架构。空掉落数组继续表示“已抽取但无掉落”，不得改成未抽取状态。
