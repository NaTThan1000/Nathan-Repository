✂ 精灵图切分工具

① 加载图片

点击选择 / 拖入 PNG 图片
建议使用原始大图（如 idle-assets.png），可含多行动画。
已处理过的单行条带也可以直接载入。

② 背景去除（色键）

绿 (0,255,0)
点色块选幕布颜色（绿 / 蓝 / 品红等任意单色背景均可）。容差越大，被判定为幕布而变透明的颜色范围越广。

③ 框选动画行 + 分割线

尚未检测

④ 动画预览

0 / 0

⑤ 导出

复制参数 → 粘贴到 CodeBuddy 对话 → 用脚本在项目文件夹内直接生成 PNG / JSON
导出每帧的内容精确包围盒坐标 {x, y, w, h}（相对整图，已去绿幕）。

操作说明

主画布操作
· 拖拽空白处 → 框选一行动画区域
· 单击选区内 → 添加分割线
· 拖动分割线 → 移动微调
· 单击分割线(不拖动) → 删除
· 拖动选区边缘/角点 → 调整选区
· 右键 → 删除最近的左侧分割线
· 紫色虚线 = 自动检测建议（仅供参考）
· 橙色实线 = 正式分割线（最终生效）
流程
① 载入大图 → ② 自动找行 → ③ 点击某行
④ 检测本行动画 → ⑤ 手动微调分割线 → ⑥ 预览 → ⑦ 导出
